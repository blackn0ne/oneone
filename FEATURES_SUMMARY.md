# ONEONE - Краткое резюме функций

## 🎯 Что можно добавить в проект на основе BookingHub

### ✅ Обязательные функции (MVP+)

1. **6 режимов бронирования**
   - ✅ Service (услуги) - базовый
   - ✅ Hotel (отели) - сезонное ценообразование, Room ID
   - ✅ Event (события) - билеты, ограничение мест
   - ✅ Online Meeting - Zoom/Google Meet интеграция
   - ✅ Rental (аренда) - транспорт/оборудование
   - ✅ Chauffeur (водитель) - такси, трансферы, Google Maps

2. **Гибкие опции бронирования**
   - ✅ Group Appointments (групповые)
   - ✅ Multiple Appointments (несколько услуг)
   - ✅ Custom Duration (кастомная длительность)
   - ✅ Recurring Appointments (повторяющиеся)

3. **Финансовые функции**
   - ✅ Flexible Rates (гибкие тарифы)
   - ✅ Extras (дополнительные услуги)
   - ✅ Packages (пакеты услуг)
   - ✅ Promo Codes (промокоды)
   - ✅ Refunds (возвраты)
   - ✅ Deposits (депозиты)
   - ✅ Payment Types (типы платежей)

4. **Автоматизация**
   - ✅ Inbox (внутренняя переписка)
   - ✅ Staff Permissions (права сотрудников)
   - ✅ Booking Rules (правила бронирования)
   - ✅ Email/SMS уведомления

### 🚀 Продвинутые функции

5. **AI Assistant**
   - Чат-бот для бронирования
   - Понимание намерений клиента
   - Проверка доступности
   - 24/7 поддержка
   - **Требует:** OpenAI API

6. **Live Form Editor**
   - Drag & drop конструктор форм
   - Готовые шаблоны (25+)
   - Персонализация
   - Мобильная оптимизация

7. **Интеграции**
   - ✅ Zapier (5000+ приложений)
   - ✅ Zoom / Google Meet
   - ✅ Google Maps
   - ✅ Email провайдеры (SendGrid, Mailgun)
   - ✅ SMS (Twilio, SMS.ru)
   - ✅ Платежные системы (Stripe, PayPal, российские)

8. **Аналитика и отчеты**
   - Дашборды
   - Статистика бронирований
   - Финансовые отчеты
   - Экспорт (CSV, Excel, PDF)

### 🌟 Уникальные предложения для ONEONE

9. **Российская локализация**
   - Полная поддержка русского языка
   - Интеграция с российскими сервисами:
     - Яндекс.Календарь
     - СМС.ru
     - ЮKassa, Сбербанк Эквайринг
     - 1С интеграция

10. **Real-time функции**
    - WebSockets для live обновлений
    - Real-time уведомления
    - Live чат

11. **Белый лейбл**
    - Кастомный брендинг
    - Собственные домены
    - Кастомные email шаблоны

12. **Marketplace**
    - Расширяемая архитектура
    - Плагины/аддоны
    - Монетизация экосистемы

## 🛠️ Технический стек

### Backend
- Laravel 12
- MySQL 8.4
- Stancl Tenancy (мультитенантность)
- Laravel Cashier (подписки)
- Spatie Permissions (роли)

### Frontend
- Inertia.js
- Vue 3
- Tailwind CSS

### Интеграции
- OpenAI API (AI Assistant)
- Zapier
- Zoom API
- Google Meet API
- Google Maps API

## 💡 Ключевые отличия от BookingHub

1. **Open Source подход** - возможность открыть базовую версию
2. **Российская локализация** - полная поддержка RU рынка
3. **Модульная архитектура** - легко расширяемая система
4. **Более гибкая тарификация** - продвинутые опции ценообразования
5. **Интеграция с российскими сервисами** - 1С, Яндекс, Сбербанк
